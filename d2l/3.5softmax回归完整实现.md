batch_size = 256

## 2. 初始化模型参数

- 输入是 28 x 28，展平后是长度 784 的向量
- 输出是 10 类，所以权重矩阵形状为 784 x 10

张量形状变化：
- 原图像: (batch, 1, 28, 28)
- 展平后: (batch, 784)
- 线性输出: (batch, 10)

```python
num_inputs = 784
num_outputs = 10

W = torch.normal(0, 0.01, size=(num_inputs, num_outputs), requires_grad=True)
b = torch.zeros(num_outputs, requires_grad=True)
```

## 3. 定义 softmax

- 线性层输出的是分数，不是概率
- softmax 把每行分数转换为概率分布，并保证每行和为 1（类似归一化指数函数）
- 指数化可以放大差异并负转正

矩阵变化：
- 输入 X 形状是 (batch, 10)
- exp 后仍是 (batch, 10)
- 每行求和得到 (batch, 1)
- 相除得到 (batch, 10) 概率 （应用广播机制）

```python
def softmax(X):
    X_exp = torch.exp(X)
    partition = X_exp.sum(1, keepdim=True)
    return X_exp / partition
```

- 这里没有做数值稳定处理，极端值可能导致上溢或下溢
- 完整版通常会在 exp 前减去每行最大值

## 4. 定义模型

- 把图像展平后进行线性变换，再通过 softmax 变成概率

矩阵变化：
- X.reshape((-1, 784)) 把每张图像拉平成一行，-1表示自动推断行数
- (batch, 784) @ (784, 10) -> (batch, 10)
- 加上 b 后仍是 (batch, 10)
- softmax 后得到概率分布 (batch, 10)

```python
def net(X):
    X = X.reshape((-1, W.shape[0])) 
    return softmax(torch.matmul(X, W) + b)
```

## 5. 定义交叉熵损失

为什么要做：
- 多分类任务中，交叉熵是最常用损失
- 它衡量了预测概率分布与真实类别之间的差距，鼓励模型把真实类别的概率最大化
- 公式：$ loss = -\sum_{i} y_i \log(\hat{y}_i) $，其中 $y_i$ 是真实类别的 one-hot 编码，$\hat{y}_i$ 是预测概率

矩阵变化：
- y_hat 形状 (batch, 10)
- y 形状 (batch,)
- 索引后得到每个样本的真实类别概率 (batch,)

```python
def cross_entropy(y_hat, y):
    return -torch.log(y_hat[range(len(y_hat)), y])
```

## 6. 分类精度

为什么要做：
- 训练时除了损失，还需要看模型是否预测正确
- 这里把概率分布转换为预测类别，再与真实标签比较

矩阵变化：
- y_hat.argmax(axis=1) 得到 (batch,);argmax 返回每行最大值的索引，即预测类别
- 与 y 比较，得到 True 或 False
- 转成数值并求和得到正确数

```python
def accuracy(y_hat, y):
    if len(y_hat.shape) > 1 and y_hat.shape[1] > 1:
        y_hat = y_hat.argmax(axis=1)
    cmp = y_hat.type(y.dtype) == y
    return float(cmp.type(y.dtype).sum())
```

## 7. Accumulator 工具

为什么要做：
- 训练过程中需要累加损失、正确数、样本数
- 提高可读性

```python
class Accumulator:
    def __init__(self, n):
        self.data = [0.0] * n

    def add(self, *args):
        self.data = [a + float(b) for a, b in zip(self.data, args)]

    def reset(self):
        self.data = [0.0] * len(self.data)

    def __getitem__(self, idx):
        return self.data[idx]
```

## 8. 评估函数

为什么要做：
- 训练之外需要在测试集上统一评估
- 评估时不需要梯度计算，节省内存，使用.eval模式达到到这一点

矩阵变化：
- net(X) 得到 (batch, 10)
- accuracy 返回正确个数

```python
def evaluate_accuracy(net, data_iter):
    if isinstance(net, torch.nn.Module):
        net.eval()
    metric = Accumulator(2)
    with torch.no_grad():
        for X, y in data_iter:
            metric.add(accuracy(net(X), y), y.numel())
    return metric[0] / metric[1]
```

## 9. 训练一个 epoch

为什么要做：
- 训练过程可复用，封装成函数更清晰
- 同时记录损失和精度，便于监控训练

矩阵变化：
- y_hat 形状 (batch, 10)
- l 形状 (batch,)
- l.sum() 得到一个标量

```python
def train_epoch_ch3(net, train_iter, loss, updater): 
    if isinstance(net, torch.nn.Module):
        net.train()
    metric = Accumulator(3)
    for X, y in train_iter:
        y_hat = net(X)
        l = loss(y_hat, y)
        if isinstance(updater, torch.optim.Optimizer):
            updater.zero_grad()
            l.mean().backward()
            updater.step()
        else:
            l.sum().backward()
            updater(X.shape[0])
        metric.add(float(l.sum()), accuracy(y_hat, y), y.numel())
    return metric[0] / metric[2], metric[1] / metric[2]
```

```python
class Animator:
    def __init__(self, xlabel=None, ylabel=None, legend=None, xlim=None,
                 ylim=None, xscale='linear', yscale='linear',
                 fmts=('-', 'm--', 'g-.', 'r:'), nrows=1, ncols=1,
                 figsize=(3.5, 2.5)):
        if legend is None:
            legend = []
        d2l.use_svg_display()
        self.fig, self.axes = d2l.plt.subplots(nrows, ncols, figsize=figsize)
        if nrows * ncols == 1:
            self.axes = [self.axes, ]
        self.config_axes = lambda: d2l.set_axes(
            self.axes[0], xlabel, ylabel, xlim, ylim, xscale, yscale, legend)
        self.X, self.Y, self.fmts = None, None, fmts

    def add(self, x, y):
        if not hasattr(y, '__len__'):
            y = [y]
        n = len(y)
        if not hasattr(x, '__len__'):
            x = [x] * n
        if not self.X:
            self.X = [[] for _ in range(n)]
        if not self.Y:
            self.Y = [[] for _ in range(n)]
        for i, (a, b) in enumerate(zip(x, y)):
            if a is not None and b is not None:
                self.X[i].append(a)
                self.Y[i].append(b)
        self.axes[0].cla()
        for x, y, fmt in zip(self.X, self.Y, self.fmts):
            self.axes[0].plot(x, y, fmt)
        self.config_axes()
        display.display(self.fig)
        display.clear_output(wait=True)
```

## 11. 训练主流程

为什么要做：
- 统一训练和测试评估
- 每个 epoch 后记录指标

矩阵变化：
- train_epoch_ch3 内部完成前向和反向传播
- evaluate_accuracy 在测试集上评估

```python
def train_ch3(net, train_iter, test_iter, loss, num_epochs, updater): #@save
    animator = Animator(xlabel='epoch', xlim=[1, num_epochs], ylim=[0.3, 0.9],
                        legend=['train loss', 'train acc', 'test acc'])
    for epoch in range(num_epochs):
        train_metrics = train_epoch_ch3(net, train_iter, loss, updater)
        test_acc = evaluate_accuracy(net, test_iter)
        animator.add(epoch + 1, train_metrics + (test_acc,))
    train_loss, train_acc = train_metrics
    assert train_loss < 0.5, train_loss
    assert train_acc <= 1 and train_acc > 0.7, train_acc
    assert test_acc <= 1 and test_acc > 0.7, test_acc
```

## 12. 设置优化器并训练

为什么要做：
- 从零实现时使用 d2l.sgd 更新参数
- 学习率 lr 控制每一步更新幅度

```python
lr = 0.1

def updater(batch_size):
    return d2l.sgd([W, b], lr, batch_size)

num_epochs = 10
train_ch3(net, train_iter, test_iter, cross_entropy, num_epochs, updater)
```

## 小结

- softmax 回归把线性输出变成概率分布
- 交叉熵用于惩罚真实类别概率过低
