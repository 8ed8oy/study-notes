## 为什么需要多尺度
在上一节中，我们默认在每个像素位置都放置锚框。这样虽然细致，但锚框数量会非常大，计算成本高。

多尺度锚框的核心思路是：
- 小目标：用更密集的采样（更大的特征图）+ 较小锚框
- 大目标：用更稀疏的采样（更小的特征图）+ 较大锚框

这样可以在计算量和检测效果之间取得平衡。

## 在特征图上均匀放置锚框
设特征图大小为 `fmap_h × fmap_w`：
- 它决定了锚框中心点在原图上的采样密度。
- 每个中心再生成若干个不同宽高比的锚框。

```python
def display_anchors(fmap_w, fmap_h, s):
    d2l.set_figsize()
    # 只关心特征图的高宽；通道数和具体数值不影响锚框中心位置
    fmap = torch.zeros((1, 10, fmap_h, fmap_w))

    # 在每个特征图位置生成锚框：1个尺度 + 3个宽高比
    anchors = d2l.multibox_prior(fmap, sizes=s, ratios=[1, 2, 0.5])

    # 锚框坐标是归一化到[0,1]的，这里还原到像素尺度便于显示
    bbox_scale = torch.tensor((w, h, w, h))
    d2l.show_bboxes(d2l.plt.imshow(img).axes, anchors[0] * bbox_scale)
```

小目标使用较大的特征图（4×4）和较小尺度。
中心点更密集，更适合覆盖小目标。

```python
display_anchors(fmap_w=4, fmap_h=4, s=[0.15])
```

中等目标将特征图降到2×2，同时增大尺度（`s=0.4`）。
采样更稀疏，但单个锚框覆盖范围更大。

```python
display_anchors(fmap_w=2, fmap_h=2, s=[0.4])
```

大目标继续降到1×1，并使用更大尺度（`s=0.8`）。
此时锚框中心几乎只在图像中心附近，更适合检测大目标。

```python
display_anchors(fmap_w=1, fmap_h=1, s=[0.8])
```

## 多尺度检测
在 CNN 中，不同层特征图对应不同大小的感受野：
- 浅层特征图分辨率高，适合小目标
- 深层特征图分辨率低，适合大目标

因此，目标检测通常会在多个层级同时预测锚框类别和偏移量。
