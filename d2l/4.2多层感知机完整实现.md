batch_size = 256
train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)

## 2. 初始化模型参数

关键点：
- 输入层把 28 x 28 展平成 784 维向量
- 隐藏层宽度设为 256（可调超参数）
- 输出层为 10 类，输出的是 logits（未归一化分数）

张量形状：
- W1: (784, 256)，b1: (256,)
- W2: (256, 10)，b2: (10,)

实现说明：
- 使用 nn.Parameter 让参数可被优化器跟踪
- 权重用小标准差正态分布初始化，偏置置零

```python
num_inputs, num_outputs, num_hiddens = 784, 10, 256

W1 = nn.Parameter(torch.randn(
    num_inputs, num_hiddens, requires_grad=True) * 0.01)
b1 = nn.Parameter(torch.zeros(num_hiddens, requires_grad=True))
W2 = nn.Parameter(torch.randn(
    num_hiddens, num_outputs, requires_grad=True) * 0.01)
b2 = nn.Parameter(torch.zeros(num_outputs, requires_grad=True))

params = [W1, b1, W2, b2]
```

## 3. 激活函数 ReLU

函数目标：
- 给模型加入非线性，使得多层网络可以拟合更复杂的函数（若一直是线性函数，则多层网络等价于单层网络）

实现细节：
- torch.zeros_like(X) 生成与 X 同形状的全零张量
- torch.max(X, 0) 等价于逐元素取 max(X, 0)
- 输出形状与输入一致

```python
def relu(X):
    a = torch.zeros_like(X)
    return torch.max(X, a)
```

## 4. 模型前向传播

函数说明：
- 先把图像展平成向量，再做两次线性变换
- 中间使用 ReLU 增加非线性
- 最后一层输出 logits，交给交叉熵损失内部处理 softmax

张量形状变化：
- 输入 X: (batch, 1, 28, 28)
- 展平后: (batch, 784)
- 隐藏层 H: (batch, 256)
- 输出 logits: (batch, 10)

```python
def net(X):
    X = X.reshape((-1, num_inputs))
    H = relu(X @ W1 + b1)
    return H @ W2 + b2
```

## 5. 损失函数

函数说明：
- 使用 nn.CrossEntropyLoss，它内部包含 softmax 与负对数似然
- 直接输入 logits 和标签即可
- reduction='none' 保留每个样本的损失，便于在训练函数中自行聚合

```python
loss = nn.CrossEntropyLoss(reduction='none')
```

## 6. 训练

函数说明：
- d2l.train_ch3 会完成：前向传播、计算损失、反向传播、更新参数
- 训练过程中记录训练损失、训练精度与测试精度
- 优化器使用 SGD，学习率和轮数是关键超参数
- updater 绑定 params，让优化器能更新 W1、b1、W2、b2
- net 输出 logits，与交叉熵直接匹配

```python
num_epochs, lr = 20, 0.15
updater = torch.optim.SGD(params, lr=lr)
train_ch3(net, train_iter, test_iter, loss, num_epochs, updater)
```

## 7. 预测

```python
predict_ch3(net, test_iter)
```

## 小结

- 多层感知机由线性层 + 非线性激活组成
- 前向传播输出 logits，交叉熵内部完成 softmax
- 训练流程与 softmax 回归类似，差异在于多了一层隐藏层
- 相较于softmax回归，训练速度更快，且训练结果损失更小，但是准确率没有明显上升
