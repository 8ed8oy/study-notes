## 2. 标签文字映射函数

函数作用：把数字标签转换为可读的文本标签。
- 输入: labels, 数字标签列表或张量
- 输出: 对应的文本标签列表

```python
def get_fashion_mnist_labels(labels):
    text_labels = [
        't-shirt', 'trouser', 'pullover', 'dress', 'coat',
        'sandal', 'shirt', 'sneaker', 'bag', 'ankle boot'
    ]
    return [text_labels[int(i)] for i in labels]
```

## 3. 可视化函数

函数作用：将一批图像按网格显示。
- imgs: 图像张量或 PIL 图像列表
- num_rows, num_cols: 网格行列数
- titles: 每张图像的标题（可选）
- scale: 控制图像显示大小

```python
def show_images(imgs, num_rows, num_cols, titles=None, scale=1.5):
    figsize = (num_cols * scale, num_rows * scale)
    _, axes = d2l.plt.subplots(num_rows, num_cols, figsize=figsize)
    axes = axes.flatten()
    for i, (ax, img) in enumerate(zip(axes, imgs)):
        if torch.is_tensor(img):
            ax.imshow(img.numpy())
        else:
            ax.imshow(img)
        ax.axes.get_xaxis().set_visible(False)
        ax.axes.get_yaxis().set_visible(False)
        if titles:
            ax.set_title(titles[i])
    return axes
```

显示一批样本图像及其标签。
此处X.shape为(18, 1, 28, 28)，表示18张图像，每张图像1个通道，大小28x28。
reshape之后变为(18, 28, 28)，去掉了通道维度，从而可以直接显示为灰度图像。（图片两个维度，数量一个维度）

```python
X, y = next(iter(data.DataLoader(mnist_train, batch_size=18)))
show_images(X.reshape(18, 28, 28), 2, 9, titles=get_fashion_mnist_labels(y));
```

## 5. 改变进程数观察运行时间

函数作用：比较不同 num_workers 下的读取速度。
- workers_list: 要测试的进程数列表
- batch_size: 小批量大小
- 返回: 每个进程数对应的耗时

```python
def benchmark_num_workers(workers_list, batch_size):
    results = []
    for num_workers in workers_list:
        loader = data.DataLoader(
            mnist_train, batch_size, shuffle=True,
            num_workers=num_workers
        )
        timer = d2l.Timer()
        for X, y in loader:
            continue
        results.append((num_workers, timer.stop()))
    return results
```

运行测试并查看不同进程数的耗时。
- 如果进程数过高，可能因调度开销而变慢
- 最优值依赖 CPU 和磁盘性能

```python
workers_list = [0, 2, 4, 8, 16, 32, 64] # 此处发现16个工作线程时，数据读取时间最短
benchmark_num_workers(workers_list, batch_size)
```

## 6. 整合所有组件

函数作用：下载 Fashion-MNIST 并返回训练与测试迭代器。
- batch_size: 小批量大小
- resize: 可选的图像尺寸调整

```python
def load_data_fashion_mnist(batch_size, resize=None):
    trans = [transforms.ToTensor()]
    if resize:
        trans.insert(0, transforms.Resize(resize))
    trans = transforms.Compose(trans)
    mnist_train = torchvision.datasets.FashionMNIST(
        root="../data", train=True, transform=trans, download=True)
    mnist_test = torchvision.datasets.FashionMNIST(
        root="../data", train=False, transform=trans, download=True)
    return (data.DataLoader(mnist_train, batch_size, shuffle=True,
                            num_workers=get_dataloader_workers()),
            data.DataLoader(mnist_test, batch_size, shuffle=False,
                            num_workers=get_dataloader_workers()))
```
