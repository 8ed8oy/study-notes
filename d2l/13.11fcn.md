## 1. 应用场景（为什么要学）
全卷积网络（Fully Convolutional Network，FCN）是语义分割的核心模型之一，用于实现图像像素到像素类别的转换。与传统卷积神经网络（用于图像分类或目标检测）不同，FCN能够将特征图的空间尺寸还原到输入图像大小，从而输出与输入图像像素一一对应的类别预测。

主要应用：
- **自动驾驶**：像素级道路、车辆、行人分割
- **医学影像**：器官、病变区域分割
- **遥感图像**：土地覆盖分类
- **图像编辑**：背景替换、滤镜效果

## 2. FCN与相关网络区别
全卷积网络与之前学习的卷积神经网络有显著区别：

- **传统CNN**：通常以全连接层结尾，输出固定长度的向量（用于分类或检测），丢失空间信息。
- **FCN**：全部由卷积层和转置卷积层构成，没有全连接层，可以接受任意尺寸的输入，输出相同尺寸的像素级预测。
- **与转置卷积关系**：FCN使用转置卷积（反卷积）将特征图上采样到输入图像尺寸，实现端到端的像素级预测。

## 3. FCN基本结构
FCN的基本设计如 :numref:`fig_fcn`所示：
1. 使用卷积神经网络（如ResNet）提取图像特征。
2. 通过$1\times 1$卷积层将通道数变换为类别个数。
3. 通过转置卷积层将特征图的高和宽变换为输入图像的尺寸。

因此，模型输出与输入图像的高和宽相同，且最终输出通道包含了该空间位置像素的类别预测。

## 4. 构建FCN模型
下面我们使用在ImageNet上预训练的ResNet-18作为特征提取器，并移除最后的全局平均池化层和全连接层，构建FCN模型。

```python
# 加载预训练的ResNet-18模型
pretrained_net = torchvision.models.resnet18(pretrained=True)
list(pretrained_net.children())[-3:]
```

ResNet-18的最后三层包括两个BasicBlock模块、全局平均池化层和全连接层。FCN不需要最后两层，因此我们截取除最后两层外的所有层。

```python
# 创建FCN网络，移除最后两层（全局平均池化和全连接层）
net = nn.Sequential(*list(pretrained_net.children())[:-2])
```

测试网络前向传播：输入尺寸为$320\times 480$的图像，经过网络后高宽缩小为原来的$1/32$（因为ResNet-18共有5个下采样阶段，每个阶段stride=2，总共$2^5=32$）。

```python
X = torch.rand(size=(1, 3, 320, 480))
net(X).shape
```

接下来添加两个关键层：
1. $1\times 1$卷积层：将512个通道转换为Pascal VOC的21个类别（20个物体类别+背景）。
2. 转置卷积层：将特征图上采样32倍，恢复到输入图像尺寸。

转置卷积层的参数设计：
- 卷积核大小：$64$
- 填充：$16$
- 步幅：$32$

这样设计是因为：如果步幅为$s$，填充为$s/2$，卷积核大小为$2s$，转置卷积会将输入的高宽放大$s$倍。

```python
num_classes = 21
net.add_module('final_conv', nn.Conv2d(512, num_classes, kernel_size=1))
net.add_module('transpose_conv', nn.ConvTranspose2d(num_classes, num_classes,
                                    kernel_size=64, padding=16, stride=32))
```

## 5. 初始化转置卷积层
在图像处理中，上采样（upsampling）常用于放大图像。双线性插值（bilinear interpolation）是常用的上采样方法，也常用于初始化转置卷积层。

双线性插值原理：
1. 将输出图像的坐标$(x,y)$映射到输入图像的坐标$(x',y')$上（根据尺寸比例）。
2. 在输入图像上找到离坐标$(x',y')$最近的4个像素。
3. 输出图像在坐标$(x,y)$上的像素值根据这4个像素及其相对距离计算。

双线性插值的上采样可以通过转置卷积层实现。下面是`bilinear_kernel`函数实现：

```python
def bilinear_kernel(in_channels, out_channels, kernel_size):
    factor = (kernel_size + 1) // 2
    if kernel_size % 2 == 1:
        center = factor - 1
    else:
        center = factor - 0.5
    og = (torch.arange(kernel_size).reshape(-1, 1),
          torch.arange(kernel_size).reshape(1, -1))
    filt = (1 - torch.abs(og[0] - center) / factor) * \
           (1 - torch.abs(og[1] - center) / factor)
    weight = torch.zeros((in_channels, out_channels,
                          kernel_size, kernel_size))
    weight[range(in_channels), range(out_channels), :, :] = filt
    return weight
```

## 6. 初始化FCN的转置卷积层
在FCN中，我们用双线性插值的上采样初始化转置卷积层。对于$1\times 1$卷积层，使用Xavier初始化参数。

```python
W = bilinear_kernel(num_classes, num_classes, 64)
net.transpose_conv.weight.data.copy_(W)
```

## 8. 训练FCN
现在可以训练全卷积网络了。损失函数和准确率计算与图像分类类似，但需要注意：
- 使用转置卷积层的通道来预测像素类别
- 需要在损失计算中指定通道维
- 模型基于每个像素的预测类别是否正确计算准确率

```python
def loss(inputs, targets):
    return F.cross_entropy(inputs, targets, reduction='none').mean(1).mean(1)
```

```python
num_epochs, lr, wd, devices = 5, 0.001, 1e-3, d2l.try_all_gpus()
trainer = torch.optim.SGD(net.parameters(), lr=lr, weight_decay=wd)
d2l.train_ch13(net, train_iter, test_iter, loss, trainer, num_epochs, devices)
```

## 9. 预测
预测时需要：
1. 将输入图像在各个通道做标准化
2. 转成卷积神经网络所需的四维输入格式

```python
def predict(img):
    X = test_iter.dataset.normalize_image(img).unsqueeze(0)
    pred = net(X.to(devices[0])).argmax(dim=1)
    return pred.reshape(pred.shape[1], pred.shape[2])
```

为了可视化预测的类别，需要将预测类别映射回它们在数据集中的标注颜色。

```python
def label2image(pred):
    colormap = torch.tensor(d2l.VOC_COLORMAP, device=devices[0])
    X = pred.long()
    return colormap[X, :]
```

## 10. 处理不同尺寸的图像
测试数据集中的图像大小和形状各异。由于模型使用了步幅为32的转置卷积层，当输入图像的高或宽无法被32整除时，输出会有偏差。

解决方案：
1. 在图像中截取多个高宽为32整数倍的矩形区域
2. 分别对这些区域做前向传播
3. 当一个像素被多个区域覆盖时，取不同区域输出的平均值作为最终预测

为简单起见，我们只读取几张较大的测试图像，并从图像的左上角开始截取形状为$320\times480$的区域用于预测。

```python
voc_dir = d2l.download_extract('voc2012', 'VOCdevkit/VOC2012')
test_images, test_labels = d2l.read_voc_images(voc_dir, False)

n, imgs = 4, []
for i in range(n):
    crop_rect = (0, 0, 320, 480)
    X = torchvision.transforms.functional.crop(test_images[i], *crop_rect)
    pred = label2image(predict(X))
    imgs += [X.permute(1,2,0), pred.cpu(),
             torchvision.transforms.functional.crop(
                 test_labels[i], *crop_rect).permute(1,2,0)]
d2l.show_images(imgs[::3] + imgs[1::3] + imgs[2::3], 3, n, scale=2)
```

## 11. 小结

- 全卷积网络先使用卷积神经网络抽取图像特征，然后通过$1\times 1$卷积层将通道数变换为类别个数，最后通过转置卷积层将特征图的高和宽变换为输入图像的尺寸。
- 在全卷积网络中，我们可以将转置卷积层初始化为双线性插值的上采样。
- FCN能够实现端到端的像素级语义分割，是语义分割领域的重要基础模型。
