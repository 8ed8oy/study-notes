# 计算机网络核心路由选择算法笔记

路由选择算法（Routing Algorithm）是网络层控制平面的核心，目标是**为网络中的所有节点对找到一条通过分组交换机网络的最低开销（Least-Cost）路径**。

根据网络拓扑信息的获取方式，路由算法主要分为两大类：

1. **全局式（集中式）路由算法**：以**链路状态（Link-State, LS）算法**为代表，所有路由器拥有完整的全局拓扑与链路开销信息。
    
2. **分散式（分布式）路由算法**：以**距离向量（Distance-Vector, DV）算法**为代表，每个节点仅与直接相连的邻居交互局部信息，以迭代方式计算最低开销路径。
    

## 一、链路状态路由算法（Link-State, LS）

### 1. 核心思想与前提

- **前提**：每个节点必须先通过链路状态广播（Link-State Broadcast）获知整个网络的拓扑图和所有链路的开销。在实际网络中（如 OSPF 协议），节点通过泛洪链路状态分组（LSP）实现全局拓扑同步。
    
- **核心算法**：**Dijkstra 算法**（贪心策略）。
    
- **计算目标**：以单节点为源节点（根），计算到达网络中所有其他节点的最短路径树（Shortest Path Tree），进而构建本节点的转发表。
    

### 2. Dijkstra 算法符号与数学定义

- $c(x, y)$：节点 $x$ 到直接相连邻居 $y$ 的链路开销。若 $x$ 与 $y$ 不相邻，则 $c(x, y) = \infty$。
    
- $D(v)$：从源节点 $u$ 到目的地 $v$ 的**当前最低路径开销**。
    
- $p(v)$：从源节点 $u$ 沿当前最低开销路径到 $v$ 时，$v$ 的**前驱节点（Predecessor）**。
    
- $N'$：**已确定最低开销路径的节点集合**。
    

### 3. 算法执行步骤（以源节点 $u$ 为例）

#### (1) 初始化（Initialization）

- 将源节点加入集合：
    
    $$N' = \{u\}$$
- 对网络中所有节点 $v$：
    
    - 若 $v$ 是 $u$ 的直接邻居，则 $D(v) = c(u, v), \quad p(v) = u$
        
    - 若 $v$ 不是 $u$ 的直接邻居，则 $D(v) = \infty, \quad p(v) = \text{null}$
        

#### (2) 迭代循环（Loop）

重复以下两步，直到所有节点都加入 $N'$（即 $N' = N$）：

1. **寻找最近节点**：在不在 $N'$ 中的所有节点中，选出当前 $D(w)$ 最小的节点 $w$：
    
    $$w \notin N' \quad \text{且} \quad D(w) = \min_{v \notin N'} D(v)$$
    
    将 $w$ 加入集合 $N'$：$N' = N' \cup \{w\}$。
    
2. **松弛更新（Relaxation）**：对所有与 $w$ 相邻且不在 $N'$ 中的节点 $v$，更新其距离值：
    
    $$D(v) \leftarrow \min \Big( D(v), \; D(w) + c(w, v) \Big)$$
    
    _若_ $D(v)$ _被更新为更小值，则将_ $v$ _的前驱节点更新为_ $w$_：_$p(v) \leftarrow w$_。_
    

### 4. 复杂度分析

- **时间复杂度**：
    
    - 朴素实现（线性查找最小值）：总共迭代 $n$ 次，第 $k$ 次循环需扫描 $n-k$ 个节点，比较次数为 $\sum_{k=1}^n (n-k) = O(n^2)$。
        
    - 优先队列/最小二叉堆优化：利用堆维护距离，提取最小值耗时 $O(\log n)$，总时间复杂度优化为 $O(\vert{}E\vert{} \log \vert{}V\vert{})$ 或 $O(n \log n)$。
        
- **空间复杂度**：存储拓扑矩阵或邻接表，为 $O(\vert{}V\vert{} + \vert{}E\vert{})$。
    

### 5. 局限与典型缺陷：路由振荡（Oscillations）

当链路开销**取决于网络承载的流量大小**（如拥塞程度/排队时延）时，LS 算法可能导致路由剧烈震荡。

- **震荡机制**：
    
    1. 初始状态流量走路径 $A$，$A$ 拥塞导致开销剧增；
        
    2. LS 算法重新计算，将所有流量瞬间切换至空闲的路径 $B$；
        
    3. 路径 $B$ 瞬间过载，开销骤增，而路径 $A$ 变为空闲；
        
    4. 下一轮广播后所有流量再次切回路径 $A$。
        
- **解决方案**：
    
    - 链路开销度量标准不应与实时流量成强强相关的单调函数。
        
    - 在各路由器执行算法的时刻中**引入随机抖动时延（Randomization）**，打散重新计算的同步周期。


## 二、距离向量路由算法（Distance-Vector, DV）

### 1. 核心思想与特点

- **去中心化（Decentralized）**：节点**不知道整个网络的全局拓扑**，仅知道与直接相连邻居的链路开销。
    
- **分布式（Distributed）与异步（Asynchronous）**：各节点独立运行，当本地链路开销改变或收到邻居的新向量时触发计算，并向所有直接邻居广播自身新的距离向量。
    
- **核心数学依据**：**Bellman-Ford 方程（动态规划思想）**。
    

### 2. Bellman-Ford 方程与核心定义

设 $d_x(y)$ 为从节点 $x$ 到节点 $y$ 的最低开销路径的开销，则递推关系式为：

$$d_x(y) = \min_{v \in \text{neighbors}(x)} \Big\{ c(x, v) + d_v(y) \Big\}$$

- **方程含义**：从 $x$ 到达 $y$ 的最优路径，必然是先从 $x$ 走到某个相邻节点 $v$（开销为 $c(x, v)$），再加上从 $v$ 到达目的地 $y$ 的最低开销 $d_v(y)$，并在所有可选邻居中取最小值。
    
- **转发表生成**：令上述方程取得最小值的邻居节点 $v^*$，即为节点 $x$ 转发去往目的地 $y$ 的**下一跳（Next Hop）**。
    

### 3. DV 算法状态维护与循环流程

每个节点 $x$ 维护以下关键状态：

1. **直接链路开销向量**：$c(x, v)$，对所有直接相连的邻居 $v$。
    
2. **自身的距离向量**：$\mathbf{D}_x = [D_x(y): y \in N]$，即 $x$ 到达网络中所有节点 $y$ 的估计最低开销。
    
3. **邻居的距离向量副本**：$\mathbf{D}_v = [D_v(y): y \in N]$，记录从每个直接邻居 $v$ 处接收到的最新距离向量。
    

#### 节点运行事件循环（Event Loop）：

```
[等待状态] 
    │
    ├─► 事件 1：本地直连链路开销 c(x, v) 发生变化
    │     或
    ├─► 事件 2：收到任意相邻节点 v 发送的新距离向量 D_v
    │
    ▼
[重新计算]
    使用 Bellman-Ford 方程重新计算自身的距离向量：
    D_x(y) = min_v { c(x, v) + D_v(y) }  (对所有 y ∈ N)
    │
    ▼
[条件广播]
    若有任意目标 y 的 D_x(y) 发生变化：
        向所有直接相连的邻居广播新的向量 D_x
    若无变化：
        静默，不发送任何信息
    │
    ▼
回到 [等待状态]
```

### 4. 关键缺陷：无穷计数与路由环路

DV 算法存在显著的非对称收敛特性：**“好消息传得快，坏消息传得慢”（Good news travels fast, bad news travels slow）**。

#### (1) 坏消息传得慢与无穷计数问题（Count-to-Infinity）

- **场景示例**：拓扑为 $X - Y - Z$，初始链路开销均为 1。
    
    - $Y$ 到 $X$ 开销为 1，下一跳为 $X$；
        
    - $Z$ 到 $X$ 开销为 2，下一跳为 $Y$。
        
- **突变故障**：$X$ 与 $Y$ 之间的链路断开（开销变为 $\infty$）。
    
    1. $Y$ 发现 $X$ 断开，但查阅邻居 $Z$ 的向量，发现 $Z$ 之前宣告“我到 $X$ 的开销是 2”；
        
    2. $Y$ 误以为可以通过 $Z$ 到达 $X$，计算得出新开销：$D_Y(X) = c(Y, Z) + D_Z(X) = 1 + 2 = 3$，下一跳设为 $Z$；
        
    3. $Y$ 向 $Z$ 宣告自己的新向量 $D_Y(X) = 3$；
        
    4. $Z$ 收到后更新：$D_Z(X) = c(Z, Y) + D_Y(X) = 1 + 3 = 4$，下一跳依然是 $Y$；
        
    5. $Y$ 与 $Z$ 之间互相将对方作为下一跳，形成了**两节点路由环路（Routing Loop）**；
        
    6. 开销逐步递增（$3 \to 4 \to 5 \to \dots$），直到达到预设的无穷大上限（如 RIP 协议中规定 16 为不可达），网络才收敛。
        

#### (2) 缓解机制：毒性逆转（Poisoned Reverse）

- **规则**：若节点 $Z$ 经由邻居 $Y$ 路由去往目的地 $X$，则 $Z$ 在向 $Y$ 宣告距离向量时，**谎称自己到** $X$ **的距离为无穷大**（即 $D_Z(X) = \infty$）。
    
- **作用**：防止 $Y$ 在链路断开后错误地选择经由 $Z$ 去往 $X$，从而直接掐断双节点环路。
    
- **局限性**：毒性逆转**只能解决两个直接相邻节点间的环路**。若涉及 3 个或以上节点的环路（例如环状拓扑 $A \to B \to C \to A$），毒性逆转失效，依然可能发生无穷计数。
    

## 三、LS 与 DV 算法全维度对比

| 比较维度         | 链路状态算法（LS）                                                       | 距离向量算法（DV）                                                                                   |
| ------------ | ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **信息范围**     | **全局信息**：每个节点拥有全网拓扑与所有链路状态                                       | **局部信息**：每个节点仅知道直连开销和邻居通告的向量                                                                 |
| **计算架构**     | **集中/独立式**：分布式广播拓扑，各节点在本地独立计算全局路径                                | **纯分布式迭代**：各节点协同交替计算，依赖邻居的中间结果                                                               |
| **基础算法**     | Dijkstra 最短路径算法                                                  | Bellman-Ford 递推方程                                                                            |
| **报文复杂度**    | 较高。需向全网广播 LSP，有 $O(\Vert{}V\Vert{} \cdot \Vert{}E\Vert{})$ 条消息传递 | 较低。仅在直接邻居之间周期性或触发式交换向量                                                                       |
| **收敛速度**     | **快**。拓扑同步后本地常数时间计算，不易产生环路                                       | **较慢**。存在坏消息慢传播，可能发生环路与无穷计数                                                                  |
| **鲁棒性与故障隔离** | **健壮性高**：<br><br>• 路由器只宣告自身直连链路的状态<br><br>• 单个节点的计算错误不会污染全局拓扑数据库 | **健壮性脆弱**：<br><br>• 路由器计算并广播的是推导出的最低开销<br><br>• 一个恶意或故障节点宣告虚假的 $0$ 开销会迅速污染全网（Blackhole/黑洞路由） |
| **典型协议代表**   | **OSPF**（开放最短路径优先）、**IS-IS**                                     | **RIP**（路由信息协议）、**BGP**（采用路径向量 Path-Vector 扩展以消灭环路）                                          |
