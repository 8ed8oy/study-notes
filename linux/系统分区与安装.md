### 准备工作

1.  **准备 U 盘**：一个 8GB 或更大容量的 U 盘（注意：制作启动盘会清空 U 盘内所有数据，请提前备份）。
2.  **下载镜像**：前往 Ubuntu 官网下载 **Ubuntu 22.04 LTS** 的桌面版 (Desktop) ISO 镜像文件。
3.  **下载烧录工具**：推荐下载 **Rufus**（轻量且免安装）。
4.  **制作启动盘**：插入 U 盘，打开 Rufus。
    * “设备”选择你的 U 盘。
    * “引导类型选择”点击右侧的“选择”，找到你下载的 Ubuntu 22.04 ISO 文件。
    * “分区类型”保持默认的 **GPT**，“目标系统”保持 **UEFI (非 CSM)**。
    * 点击“开始”，等待写入完成。

### 第一阶段：BIOS 设置

为了让系统顺利引导并兼容后续的硬件驱动（尤其是深度学习相关的环境），需要调整 BIOS：

1.  重启电脑，在开机亮屏的瞬间狂按进入 BIOS 的快捷键（通常是 `F2`、`F12`、`Del` 或 `Esc`，取决于你的电脑品牌）。
2.  在 BIOS 中找到 **Secure Boot（安全启动）** 并将其设置为 **Disabled（禁用）**。这一步非常关键，否则后续安装某些专有驱动（如显卡驱动）时会被拦截。
3.  保存并退出 BIOS (通常是 `F10`)。

### 第二阶段：进入安装程序

1.  再次重启，开机时狂按 **Boot Menu（启动菜单）** 快捷键（通常是 `F12`、`F8` 或 `F11`）。
2.  在列表中选择你的 U 盘启动（通常带有 "UEFI" 和你 U 盘品牌的字样）。
3.  进入 GRUB 菜单后，选择 **Try or Install Ubuntu**。
4.  进入桌面后，双击桌面上的 **Install Ubuntu 22.04 LTS** 图标。

### 第三阶段：系统安装与高能预警（分区）

前面的语言（建议先选中文，方便看懂）、键盘布局、无线网络等按提示正常选择即可。在“更新和其他软件”界面，建议选择**正常安装**，并勾选“为图形或无线硬件...安装第三方软件”。

**核心操作来了——“安装类型”界面：**

千万**不要**选“与 Windows 共存”，一定要选择最下面的 **其他选项 (Something else)**，这样可以手动接管分区，确保你刚刚划出的 256GB 被正确利用。

找到你那 256GB 的“空闲 (Free space)”区域。选中它，点击左下角的 `+` 号，按以下方案划分为三个核心分区。

考虑到你后续会大量使用 Docker、编译 C++ 工程以及进行深度学习训练，我建议采用**不单独划分 `/home` 的大根目录方案**。因为 Docker 的镜像和很多系统级依赖默认全塞在根目录，单独拆分很容易导致根目录爆满。

**1. EFI 系统分区 (引导分区)**
* **大小**：`512` MB
* **新分区的类型**：主分区 (Primary)
* **新分区的位置**：空间起始位置 (Beginning of this space)
* **用于**：EFI 系统分区 (EFI System Partition)

**2. Swap 交换空间 (虚拟内存)**
* **大小**：`16384` MB (即 16GB。如果在编译庞大的 ROS 包时物理内存不够，Swap 能救命)。
* **新分区的类型**：逻辑分区 (Logical)
* **新分区的位置**：空间起始位置
* **用于**：交换空间 (swap area)

**3. 根目录 `/` (核心系统与数据)**
* **大小**：剩余的全部空间（大约 240GB 左右）
* **新分区的类型**：主分区 (Primary)
* **新分区的位置**：空间起始位置
* **用于**：`Ext4` 日志文件系统
* **挂载点**：`/`

### 第四阶段：收尾与引导设置

1.  **安装启动引导器的设备 (Device for boot loader installation)**：
    在分区界面的最下方，有一个下拉菜单。**必须**选择你刚刚创建的那个 512MB 的 **EFI 系统分区**（留意它的编号，比如 `/dev/nvme0n1pX` 或 `/dev/sdaX`）。
2.  确认无误后，点击“现在安装”。系统会弹出一个警告框让你确认分区改动，点击“继续”。
3.  设置时区（Shanghai），设置你的计算机名、用户名和密码。
4.  等待安装进度条跑完。完成后，系统会提示你重启。点击“现在重启”，并在屏幕提示 `Please remove the installation medium, then press ENTER` 时，**拔掉 U 盘**并按回车。

重启后，你应该会看到经典的 GRUB 紫色/黑色引导界面，第一项是 Ubuntu，中间某一项是 Windows Boot Manager。这就代表你的双系统彻底大功告成了！你可以选择 Ubuntu 进入开始配置你的开发环境了。

---
Intel Ultra 7（Meteor Lake 架构）采用了全新的 Arc 核显和 NPU 架构，而 Ubuntu 22.04 最初发布时默认的基础内核（5.15 版本）比较老，根本“不认识”这些新硬件。这导致图形界面的底层服务（X11/Wayland）启动失败，这就是你卡在黑屏、闪烁光标或无法进入桌面的根本原因。

关于 **HWE（Hardware Enablement，硬件使能）**，网上的信息可能有些滞后：
现在 Ubuntu 官网并没有单独名为“HWE版”的镜像下载链接。因为**只要你下载的是 Ubuntu 22.04.4 或 22.04.5 的最新 Desktop 桌面版镜像，它默认就已经自带了 HWE 内核（通常是 6.5 或 6.8 版本内核）**。

如果在安装后依然无法进入桌面，我们可以通过一个经典的 Linux 抢救技巧，先强制进入系统，再通过命令行升级 HWE 并安装对应驱动。

### 第一步：进入安全图形模式（临时绕过驱动）
我们需要让系统以“纯软件渲染”的基础模式启动，先挤进桌面再说。

1.  重启电脑，在进入双系统选择界面（GRUB 菜单，黑或紫底白字的界面）时，光标停留在 **Ubuntu** 那一项上。
2.  按下键盘上的字母 **`e`** 键，进入启动参数编辑模式。
3.  在屏幕文本中找到以 `linux` 开头的那一行（通常比较长，行末或中间有 `quiet splash` 字样）。
4.  在 `quiet splash` 的后面，空一格，手动输入 **`nomodeset`**。
    *修改后看起来大概像这样：`... quiet splash nomodeset ...`*
5.  按下 **`F10`** 键（或 `Ctrl + X`）引导启动。

*注：这只是临时生效的一次性操作，它禁用了所有显卡加速。成功的话，你现在应该能看到一个分辨率较低、略显卡顿的 Ubuntu 桌面了。*

### 第二步：联网并通过指令安装/更新 HWE
成功进入桌面后，连上 Wi-Fi 或插上网线，打开终端（快捷键 `Ctrl + Alt + T`），按顺序执行以下三条指令。

**1. 更新本地软件包列表**
```bash
sudo apt update
```

**2. 安装 Ubuntu 22.04 的 HWE 内核与图形栈**
哪怕你下载的镜像自带了，这条命令也能确保你将其完整补齐并设为默认：
```bash
sudo apt install --install-recommends linux-generic-hwe-22.04 xserver-xorg-hwe-22.04
```

**3. 升级所有基础库**
```bash
sudo apt upgrade -y
```

### 第三步：重启并验证
终端跑完所有进度条后，输入 `reboot` 重启电脑。
这一次**不需要**再按 `e` 修改任何东西，直接正常回车选择 Ubuntu 启动。

系统重启后，应该就能以正常的高分辨率进入流畅的桌面了。你可以再次打开终端，输入 `uname -r` 检查一下：如果输出结果是 `6.5.x` 或 `6.8.x` 开头（而不是 5.15），就说明 HWE 升级成功，你的 Intel Ultra 7 已经被系统正确识别。接下来就可以开始配置 ROS 和 Docker 环境了。
