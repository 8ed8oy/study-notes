### 📦 推荐补充安装的专业软件

考虑到在 Ubuntu 22.04 环境下进行深度的算法开发、物理仿真和系统级构建，以下工具将大幅提升你的工程体验：

#### 1. 机器人与物理仿真底层依赖
如果后续需要运行 Isaac Gym、MuJoCo 或基于 ROS 2 的物理仿真器，Ubuntu 桌面版默认缺少一些图形与渲染依赖库。建议提前补齐：
```bash
sudo apt-get install -y libvulkan1 vulkan-tools libxcursor-dev libxrandr-dev libxinerama-dev libxi-dev mesa-vulkan-drivers
```

#### 2. ROS 2 Humble Hawksbill
Ubuntu 22.04 是 ROS 2 Humble 的官方支持平台（LTS）。如果你从事具身智能、硬件控制或 VLA 模型端到端部署，ROS 2 是绕不开的中间件。建议不要用 Conda 安装，而是直接安装系统级二进制包 (`ros-humble-desktop`)，以获得最完善的 rviz2 和 rqt 工具链支持。

#### 3. 终端多路复用与增强：Terminator
虽然系统安装了 Tmux（适合后台挂机训练），但在图形界面下进行多节点调试时（例如同时开启控制节点、视觉节点、仿真界面），一个支持任意分割窗口、组播命令的图形终端会更直观。
```bash
sudo apt-get install -y terminator
```

#### 4. 高性能代码搜索工具：ripgrep (rg)
在庞大的 C++ 或 Python 项目（如框架源码）中搜索变量或类名，传统的 `grep` 速度较慢。`ripgrep` 是目前公认最快的文本搜索工具。
```bash
sudo apt-get install -y ripgrep
```

* **系统级 CUDA Toolkit (通过 Runfile 安装)**：
    * **原因**：虽然通过 `conda install pytorch` 会自带运行时的 CUDA 库，但当你需要从源码编译某些 C++ 扩展、自定义算子，或者配置 Isaac Gym 这样的物理仿真环境时，往往需要系统环境变量中存在 `nvcc` 编译器。
    * **致命避坑**：**绝对不要**使用 `sudo apt install nvidia-cuda-toolkit`（版本通常极老），也**绝对不要**使用 NVIDIA 官方的 `.deb` 包安装（会强制覆盖掉我们在脚本 1 中安装好的、与桌面兼容最好的闭源显示驱动，导致黑屏重启）。
    * **正确做法**：去官网下载 `.run` 格式的安装包。执行安装时，**务必在图形界面取消勾选 "Driver"（驱动）选项**，仅安装 CUDA Toolkit。

* **Zsh 插件双雄**：
    * `zsh-autosuggestions`：根据历史命令提供灰色补全提示，按方向键右键直接补全（极度提高效率）。
    * `zsh-syntax-highlighting`：命令语法高亮，敲错命令显示红色，敲对显示绿色。
* **fzf (Fuzzy Finder)**：
    * 命令行模糊查找神器。安装后按下 `Ctrl+R`，你可以以前所未有的速度搜索历史复杂命令；或者用来快速搜索并进入嵌套极深的工程目录。
* **zoxide**：
    * 更智能的 `cd` 命令替代品（Rust 编写）。它会记住你常用的路径，比如你只需输入 `z gitlet`，它就能瞬间跳转到你之前去过的工作区。

考虑到你可能会在实验室、自习室通过笔记本远程连接这台主力机：
* **OpenSSH Server**：
    * 基础必备：`sudo apt install openssh-server`。允许你通过局域网 SSH 连入，VSCode 也极度依赖它来进行 Remote-SSH 开发。
* **组网工具 (Tailscale 或 ZeroTier)**：
    * 如果主力机没有公网 IP，强烈建议安装 Tailscale（基于 WireGuard 的 P2P 组网）。它能为你所有的设备分配一个固定的内网 IP，让你无论在校园哪个角落，都能顺畅地 SSH 登录主力机跑模型或查代码，无需配置复杂的反向代理。

* **Meld** 或 **Beyond Compare**：
    * 优秀的图形化 Git Diff 工具。当你处理复杂的 C++ 代码冲突或对比庞大的 JSON 配置文件时，终端的 `diff` 会让人眼花缭乱，Meld 会直观很多。
* **tldr**：
    * 太长不看版的 `man` 手册。比如你忘了 `tar` 解压参数，打 `tldr tar` 会直接给你最常用的 3 个例子，而不是几百行的英文文档。可以直接通过 `pipx install tldr` 安装。

这套环境搭完，你的 Ubuntu 就是一台同时兼顾工业级 C++ 开发、隔离纯净的深度学习环境，以及极其稳定日常体验的“战斗机”了。遇到任何环境冲突，多用 Docker 或 Conda 隔离，保持宿主系统（那 128G 空间）的纯净。
